## 🌐 How to Create a Private Link For Her in 1 Minute (Free)

### Method 1: Netlify Drop (Easiest - No Sign-up Required)
1. Go to **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop the whole **`ForYou`** folder into the circle on the web page.
3. In 5 seconds, you will get a private link (e.g. `https://magical-surprise-nandini.netlify.app`)!
4. Send the link + the passcode **`511303`** to her on WhatsApp/Instagram!

### Method 2: Vercel (Fast & Beautiful)
1. Go to **[vercel.com](https://vercel.com)**.
2. Click **Add New... -> Project** and drag & drop the `ForYou` folder.
3. Click **Deploy**.

### Method 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings -> Pages** -> select `main` branch -> **Save**.
3. Your live link will be ready!

## 📸 How to Add Your Photos
1. Put your photos into the `assets/photos/` folder named `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, `photo5.jpg`.
2. Open `config.js` and update `image:` paths to `"assets/photos/photo1.jpg"`, etc.
3. You can also customize the romantic notes and captions inside `config.js`!

---

## 💌 How to Customize
- All settings, texts, and reasons are configured in [`config.js`](./config.js):
  - **Passcode**: `511303` (under `CONFIG.security.passcode`)
  - **Recipient**: `Nandini` / `Kunju`
  - **Birthday**: `November 5`
  - **Love Reasons**: `CONFIG.reasons`
  - **Love Letter**: `CONFIG.letter`
